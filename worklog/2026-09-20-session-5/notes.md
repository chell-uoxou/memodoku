# メモ 2026-09-20 session-5

## ロゴの原本
- `public/favicon.svg`（鼻あり・タイル付き）と `public/cat.svg`（鼻を埋めた猫だけ）が Affinity 側の原本。
  `src/components/ui/catPath.ts` の `CAT_PATH` は cat.svg の d をそのまま写したもの。
  形を変えるときは3つを揃えること。cat.svg は実行時には読まれない（パスの写し元として置いてある）。
- 輪郭のパラメータ: 耳の折れ点 `L12 52` / `L88 52`（下げると傾斜がゆるく、上げるときつくなる）。
  眉間は頭頂のハンドル長で調整（6 → 10 に伸ばして緩くした）。鼻は上辺 y=40 の 15x12。
- 耳の先と谷は R1.5。同じ R でも角度が鋭いほど辺を長く食う（耳の先 40.7° → 4.05、谷 91.2° → 1.47）。
  耳の外側の付け根は 171.5° でほぼ直線なので、R1.5 だと 0.11 しか効かず見えない。

## 猫印の大きさ
- バツは 26→74 を線幅11の丸端で引くので外形が 59x59。猫はこれに合わせて `CAT_SCALE = 0.629`。
- 白フチ `CAT_STROKE = 6` は縮めても太さを変えない。領域色の上での可読性のため。
  スケール後の座標系で引くので `6 / CAT_SCALE` と割り戻す。Canvas の lineWidth も同じ。
- 盤面 / サムネイル / 共有画像の3箇所が同じ定数を使う。1箇所だけ直すとズレる。
